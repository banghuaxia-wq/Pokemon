# 🎮 宝可梦技能系统使用说明

## 📚 系统架构

### 三层设计

1. **数据层（SkillData）** - ScriptableObject，存储静态技能数据
2. **实例层（Skill）** - 运行时对象，追踪PP值等动态状态
3. **表现层（PokemonFromData）** - 宝可梦执行技能并播放动画

---

## 🛠️ 如何创建技能

### 步骤1：创建技能数据资源

1. 在Project面板中右键
2. 选择 `Create → Pokemon → Skill Data`
3. 命名技能（如"Tackle_撞击"）
4. 在Inspector中填写：
   - **Skill Name**: 撞击
   - **Description**: 用整个身体撞向对手
   - **Skill Type**: Physical（物理攻击）
   - **Target Type**: Enemy（敌方单体）
   - **Power**: 40（威力）
   - **Max PP**: 35（使用次数）
   - **Accuracy**: 100（命中率）

### 步骤2：为宝可梦添加技能

1. 选中场景中的宝可梦GameObject
2. 找到 `PokemonFromData` 组件
3. 在 `Skill Data Array` 中拖入刚创建的技能数据
4. 最多可添加4个技能

## 🎯 代码运行流程

### 初始化流程

```
游戏开始
    ↓
PokemonFromData.Awake()
    ↓
InitializeSkills() - 根据 skillDataArray 创建 Skill 实例
    ↓
每个 Skill 从 SkillData 读取数据，初始化 currentPP = maxPP
```

### 使用技能流程

```
玩家点击技能按钮
    ↓
调用 Skill.Use()
    ↓
检查 HasPP（是否有PP）
    ↓
消耗1点PP (currentPP--)
    ↓
PokemonFromData.PlayAttackAnimation(skillType)
    ↓
根据技能类型触发对应动画 Trigger
    ↓
计算伤害并应用到目标
    ↓
目标.TakeDamage(伤害值)
```

## 📖 核心类详解

### 1. SkillData（技能数据）

**作用**: 存储技能的静态数据（不会改变）

**关键字段**:
- `skillName`: 技能名称
- `power`: 威力值
- `maxPP`: 最大PP值
- `skillType`: 技能类型（决定动画）

**使用方式**: 
- 作为ScriptableObject资源存在
- 可以被多个宝可梦共享
- 不存储运行时状态

### 2. Skill（技能实例）

**作用**: 运行时技能对象，追踪PP等状态

**关键字段**:
- `data`: 引用SkillData
- `_currentPP`: 当前剩余PP值（会变化）

**关键方法**:
- `Use()`: 使用技能，消耗1点PP
- `HasPP`: 检查是否还有PP
- `RestorePP()`: 恢复PP

**使用方式**:
```csharp
// 获取宝可梦的技能
Skill skill = pokemon.GetSkills()[0];

// 检查能否使用
if (skill.HasPP)
{
    // 使用技能
    if (skill.Use())
    {
        // 执行技能效果
        int damage = skill.power;
    }
}
```

### 3. PokemonFromData（宝可梦）

**作用**: 宝可梦实例，管理技能和动画

**关键字段**:
- `skillDataArray`: 配置的技能数据（Inspector中拖入）
- `skills`: 运行时技能实例列表
- `animator`: 动画控制器

**关键方法**:
- `GetSkills()`: 获取技能列表
- `PlayAttackAnimation(skillType)`: 根据技能类型播放动画

## 🎨 动画系统集成

### Animator设置

为每个宝可梦的Animator添加触发器（Trigger）：

1. **PhysicalAttack** - 物理攻击动画（撞击、抓等）
2. **SpecialAttack** - 特殊攻击动画（火焰、水炮等）
3. **StatusSkill** - 状态技能动画（变硬、睡觉等）
4. **Heal** - 治疗动画

### 工作原理

```
技能类型 → Trigger名称 → 动画
----------------------------------------
Physical → PhysicalAttack → 皮卡丘的撞击动画
Physical → PhysicalAttack → 小火龙的撞击动画（不同动画！）
Special  → SpecialAttack  → 皮卡丘的十万伏特动画
```

**关键设计**: 
- 相同的技能类型（Physical）
- 触发相同的Trigger名称（PhysicalAttack）
- 但每个宝可梦播放自己的动画

## 💡 实际应用示例

### 示例：创建"撞击"技能

#### 1. 创建技能数据
```
Assets/ScriptableObjects/Skills/Tackle.asset
- Skill Name: 撞击
- Skill Type: Physical
- Power: 40
- Max PP: 35
```

#### 2. 为两个宝可梦添加
```
皮卡丘:
  skillDataArray[0] = Tackle.asset
  
小火龙:
  skillDataArray[0] = Tackle.asset
```

#### 3. 设置各自的动画
```
皮卡丘 Animator:
  PhysicalAttack → 皮卡丘奔跑撞击动画
  
小火龙 Animator:
  PhysicalAttack → 小火龙跳跃撞击动画
```

#### 4. 使用时
```csharp
// 无论是皮卡丘还是小火龙
pokemon.GetSkills()[0].Use();  // 使用撞击
pokemon.PlayAttackAnimation(SkillType.Physical);  // 播放各自的动画
```

## 🚀 进阶扩展

### 添加新的技能类型

1. 在 `SkillType.cs` 中添加枚举值
2. 在 `PokemonFromData.PlayAttackAnimation()` 中添加对应case
3. 在Animator中添加对应Trigger

### 添加技能特效

可以在技能数据中添加：
- 特效预制体引用
- 音效引用
- 摄像机震动参数

### PP恢复系统

```csharp
// 恢复单个技能
skill.RestorePP();

// 恢复所有技能
foreach (var skill in pokemon.GetSkills())
{
    skill.RestorePP();
}
```

## 📝 总结

### 数据与表现分离的优势

✅ **技能可共享**: 多个宝可梦使用同一个SkillData
✅ **动画独立**: 每个宝可梦有自己的动画表现
✅ **易于扩展**: 添加新技能只需创建新的ScriptableObject
✅ **性能优化**: ScriptableObject在内存中只有一份
✅ **状态独立**: 每个宝可梦的PP值独立追踪

### 你的设计思路完全正确！

这是游戏开发中的标准模式，被广泛应用于各种游戏中。
