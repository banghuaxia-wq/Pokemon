# 🎮 野生与玩家宝可梦系统完整教程

## 📚 系统架构

### 核心设计理念

```
野生宝可梦流程：
PokemonData (ScriptableObject) → Prefab → 实例化 → InitializeAsWild() → 战斗

玩家宝可梦流程：
PlayerInventory (背包) → PlayerPokemonData (存档数据) → 实例化 → InitializeAsPlayer() → 战斗 → SyncToPlayerData() → 保存
```

## 🗂️ 数据结构说明

### 1. PokemonData（种族数据）
- **类型**: ScriptableObject
- **作用**: 存储宝可梦种族的静态数据
- **用于**: 野生宝可梦模板、玩家宝可梦的基础数据

```csharp
[CreateAssetMenu]
public class PokemonData : ScriptableObject
{
    public string displayName;        // 种族名称
    public int baseHP;                // 基础HP
    public int baseAttack;            // 基础攻击
    public int baseDefense;           // 基础防御
    public List<SkillData> skills;    // 默认技能列表
}
```

### 2. PlayerPokemonData（玩家宝可梦数据）
- **类型**: 可序列化类
- **作用**: 存储玩家宝可梦的运行时数据
- **用于**: 背包系统、存档

```csharp
[Serializable]
public class PlayerPokemonData
{
    public PokemonData pokemonData;         // 种族数据引用
    public string nickname;                 // 昵称
    public int level;                       // 等级
    public int currentHP;                   // 当前HP
    public List<SkillData> learnedSkills;   // 已学会的技能
    public List<int> skillCurrentPP;        // 各技能的当前PP
}
```

### 3. PokemonFromData（战斗实例）
- **类型**: MonoBehaviour
- **作用**: 战斗场景中的宝可梦实例
- **用于**: 实际战斗、动画播放

## 📝 关键代码解析

### 野生宝可梦初始化

```csharp
public void InitializeAsWild()
{
    isPlayerPokemon = false;
    playerData = null;
    
    // 从PokemonData读取
    _currentHP = pokemonHP;
    
    // 技能从PokemonData.skills复制，PP满
    foreach (var skillData in data.skills)
    {
        skills.Add(new Skill(skillData));  // PP自动设为maxPP
    }
}
```

### 玩家宝可梦初始化

```csharp
public void InitializeAsPlayer(PlayerPokemonData playerPokemonData)
{
    isPlayerPokemon = true;
    playerData = playerPokemonData;
    data = playerPokemonData.pokemonData;
    
    // 从PlayerPokemonData读取
    _currentHP = playerPokemonData.currentHP;
    
    // 技能从learnedSkills读取，恢复存档中的PP
    for (int i = 0; i < playerData.learnedSkills.Count; i++)
    {
        Skill skill = new Skill(playerData.learnedSkills[i]);
        skill.SetCurrentPP(playerData.skillCurrentPP[i]);  // 恢复PP
        skills.Add(skill);
    }
}
```

### 战斗结束同步数据

```csharp
public void SyncToPlayerData()
{
    if (!isPlayerPokemon || playerData == null) return;
    
    // 同步HP
    playerData.currentHP = _currentHP;
    
    // 同步PP
    playerData.skillCurrentPP.Clear();
    foreach (var skill in skills)
    {
        playerData.skillCurrentPP.Add(skill.currentPP);
    }
}
```

## 💡 常见问题

### Q1: 为什么要分开PokemonData和PlayerPokemonData？

**A**: 
- **PokemonData**: 所有皮卡丘共享的种族数据（不变）
- **PlayerPokemonData**: 你的皮卡丘的个体数据（会变）

类比：
- PokemonData = 人类（种族）
- PlayerPokemonData = 张三（个体）

### Q2: 野生宝可梦的技能可以改吗？

**A**: 可以！在PokemonData.skills中配置。所有从这个数据生成的野生宝可梦都会有这些技能。

### Q3: 玩家宝可梦的昵称在哪里设置？

**A**: 
```csharp
PlayerPokemonData myPikachu = /* 获取 */;
myPikachu.nickname = "皮皮";
```

### Q4: 如何让玩家宝可梦升级？

**A**: 
